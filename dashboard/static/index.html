Models

The model store of AGX02 and its control.

Control mode Not known

Models SIMULATED

Each row is one model version of the store (~/agx-models). A row without a version comes from config/models.yaml or from the agx-infer status only.

  • Build: makes an engine from the ONNX file on this AGX. It is possible for NEEDS BUILD, or for FAILED with an ONNX file and no engine.
  • Activate: starts a READY or FAILED version on the cameras that you select.
  • Deactivate: stops an ACTIVE version. The other models continue.
  • Rollback: puts the last good set of models back.

Each action has a confirmation step. AGX02 can refuse an action (for example in vehicle mode). The page then shows the reason. No action deletes a model version.

Results/s and latency: from agx-infer on AGX02 (latency = total time of the model). Open a row to see all its values.

GPU memory values are an estimate (engine file + activation + I/O).
